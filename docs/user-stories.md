## Customer
1. As a customer, I want to review the estimated cost of the repair, so that I can approve or reject the proposed work. 

2. As a customer, I want to view the available services and their prices on the website, so that I do not have to call the shop to ask about prices.
Acceptance criteria
-The website displays the available repair services and their current prices.
-Each service displays its name and current price.
-When there are no services available, the website displays a message indicating that there are no services available.


## Counter manager
3. As a counter manager, I want to register a customer, so that I can have their information available when needed.

4. As a counter manager, I want to register a bicycle with its identifying information, so that I can correctly identify it throughout the repair.
Acceptance Criteria
-The registration screen allows the counter manager to enter the bicycle's brand, model, color, and serial number.
-After registration, the bicycle's identifying information is displayed on its bicycle record.
-The system does not allow two bicycles to be registered with the same serial number.

5. As a counter manager, I want to contact the customer with the estimated cost, so that they can approve or reject the proposed work before it begins.

6. As a counter manager, I want to notify the customer when their bicycle is ready, so that they can come and pick it up.

7. As a counter manager, I want to record the final amount charged for a repair, so that the amount paid can differ from the standard service price when necessary.

8. As a counter manager, I want to record a bicycle's ownership history, so that the repair history remains associated with the bicycle when it changes owners.

## Mechanic 
9. As a mechanic, I want to take photos of a bicycle when it arrives, so that there is evidence of its condition before the repair.

10. As a mechanic, I want to inspect a bicycle, so that I can identify its problems and determine what work it needs.

11. As a mechanic, I want to estimate the repair time, so that the customer can be given a promised completion date.

12. As a mechanic, I want to perform the approved repair work, so that the bicycle can be restored and prepared for the customer.

13. As a mechanic, I want to view a bicycle's repair history, so that I can know what work has been done to it before.
Acceptance criteria
-The bicycle's previous repairs are displayed in chronological order.
-Each previous repair displays the work that was performed on the bicycle.
-When the bicycle has no previous repairs, the screen displays a message indicating that there is no repair history available.

## Owner
14. As an administrator, I want to update the prices of available services, so that the current price list is accurate.

15. As an administrator, I want to view the history of service prices, so that I can keep track of how prices have changed over time.

16. As an owner, I want to see which bicycles have passed their promised completion date, so that I can identify delayed repairs before the customer calls.
Acceptance criteria
-The screen displays the promised completion date for each active repair.
-Repairs whose promised completion date has passed are clearly identified as delayed.
-When there are no delayed repairs, the screen displays a message indicating that there are no delayed repairs.
